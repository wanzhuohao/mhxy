# 性能与稳定性优化方案

日期：2026-06-06

## 背景

当前 5 个窗口各一个线程并行执行任务，存在两个问题：
1. 截图用 `pyautogui.screenshot()`，单次 ~100ms，5 线程并发时更慢
2. 所有线程共用一把点击锁，5 个窗口排队点击，实际上不同窗口的点击互不干扰

## 优化项

### 1. mss 替换截图（性能提升 5~7 倍）

**现状**：`pyautogui.screenshot()` → PIL Image → numpy → 灰度，单次 ~100ms

**方案**：用 `mss` 库直接抓帧，单次 ~15ms

**改动范围**：仅 `business.py` 的 `_screenshot_gray` 函数

**实现**：
```python
import mss
_sct = mss.mss()

def _screenshot_gray(region=None):
    if region is None:
        wr = get_window_rect()
        if wr is not None:
            region = wr
    if region:
        monitor = {"left": region[0], "top": region[1], "width": region[2], "height": region[3]}
    else:
        monitor = _sct.monitors[0]
    shot = _sct.grab(monitor)
    arr = np.array(shot)[:, :, :3]  # BGRA → BGR
    return cv2.cvtColor(arr, cv2.COLOR_BGR2GRAY)
```

**注意**：
- `mss.grab` 返回 BGRA 格式，需要截取前 3 通道
- `_sct` 保持模块级单例，不要每次创建
- `pyautogui.screenshot` 的其他用途（抓点颜色）保留不变

### 2. 每窗口一把点击锁

**现状**：全局 `_click_lock`，所有线程排队点击

**方案**：每窗口独立锁，不同窗口可同时点击，同窗口内串行

**改动范围**：`business.py` + `mhxy.py`

**实现**：
```python
# business.py
_window_locks = {}
_window_locks_lock = threading.Lock()

def get_window_lock(hwnd):
    with _window_locks_lock:
        if hwnd not in _window_locks:
            _window_locks[hwnd] = threading.Lock()
        return _window_locks[hwnd]

def safe_click(hwnd, x, y):
    lock = get_window_lock(hwnd)
    with lock:
        pyautogui.click(x, y)
```

**影响范围**：
- `safe_click` 签名变化：增加 `hwnd` 参数
- `find_and_click` 需要传入 `hwnd`
- 线程上下文增加 `hwnd` 字段：`set_window_context(hwnd, rect)`
- `_window_task_thread` 调用 `set_window_context(hwnd, rect)`

**调用链**：
```
_window_task_thread(hwnd, rect, func, name)
  → set_window_context(hwnd, rect)  # 存 hwnd + rect
  → func()
    → find_and_click(...)
      → safe_click(hwnd, x, y)  # 从上下文取 hwnd
```

### 3. 失败重试 3 次

**现状**：任务步骤失败直接跳过或卡死

**方案**：关键操作失败时自动重试 3 次，间隔 2 秒，全部失败则飞书通知并跳过

**改动范围**：`business.py` 各任务函数

**实现**：
```python
def _retry(func, max_retries=3, delay=2):
    """重试装饰器，失败重试 N 次"""
    for i in range(max_retries):
        try:
            result = func()
            if result is not False and result is not None:
                return result
        except Exception as e:
            log(f"第{i+1}次执行失败: {e}", "WARN")
        if i < max_retries - 1:
            time.sleep(delay)
    return False
```

**使用方式**：
```python
# 改前
find_and_click_path('fubentiaoguo.bmp', yuzhi=0.65, region=FUBEN_REGION)

# 改后
_retry(lambda: find_and_click_path('fubentiaoguo.bmp', yuzhi=0.65, region=FUBEN_REGION))
```

**重点应用**：
- 副本任务的每个点击步骤
- 宝图任务的搜索点击
- 秘境任务的战斗判断
- 一条龙中的每个子任务入口

**不需要重试的**：
- 等待类操作（`_wait`）
- 已有循环重试逻辑的（师门的 15 次循环）

## 实施顺序

1. **mss 替换截图** — 改动最小，收益最大，先做
2. **每窗口点击锁** — 需要改函数签名，影响面较大，第二步
3. **失败重试** — 逐个任务函数添加，可以渐进式推进
