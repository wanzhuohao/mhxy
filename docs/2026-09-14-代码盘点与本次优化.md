# 梦幻西游辅助工具 代码盘点与本次优化

日期：2026-09-14

## 一、盘点结论（只读分析）

**基本盘**
- 独立 git 仓库，`main` 分支，工作区干净。
- 18 个 Python 文件全部 `py_compile` 通过（Python 3.12.2）。
- 依赖：mss 截图、OpenCV 模板匹配、pyautogui 点击、tkinter GUI、每窗口点击锁（多线程并行）。
- 13 个任务全部注册为「组队型」（只执行一次），`INDEPENDENT_TASKS` 为空集，并行分支已不生效。

**高优先级问题**
1. `watu.py` 用裸 `pyautogui.doubleClick()`（跳过窗口点击锁）：多窗口并发时可能重复/漏点。——**本次已修**
2. 大量硬编码坐标 + 窗口1固定区域（`REGIONS`，2560×1440）；分辨率一旦变化全盘失效。用户明确**不做自适应**，维持现状。
3. 科举/三界注释自相矛盾（问及"满10次"，判 `>=12` 停）。——**本次已对齐注释**
4. 无自动化测试，仅靠跑游戏截图回归。

**低优先级**
- 函数内 `import` 多处（watu/zhuogui/baotu/dati），风格不统一。
- `core.py` region 语义混用（`(x0,y0,x1,y1)` 与窗口 rect `(x,y,w,h)` 混用）。
- `notify.py` 启动同步读 config.json，损坏即崩；`mhxy.py` 含 GUI 逻辑与任务调度耦合。

## 二、本次优化（已落地）

### 1. 挖图双击改为带锁双击
- 新增 `context.safe_double_click(x, y)`：与 `safe_click` 一致，同窗口串行、不同窗口并行。
- `watu.py` 的宝图双击改为调用 `safe_double_click`，不再裸调 `pyautogui.doubleClick`。

### 2. 科举求助次数注释/日志对齐
- 实际逻辑：目标 10 次求助，为避免个别点击被游戏吞掉，容错到 12 次才判定该窗口完成。
- 注释与日志统一表述为「目标 10 / 容错至 12」，原"满10次""求助n/12"表述已修正。

### 3. 本次仅改动
- `src/context.py`：新增 `safe_double_click`
- `src/tasks/watu.py`：改用 `safe_double_click`
- `src/tasks/dati.py`：科举注释与日志表述对齐

均通过 `py_compile`。
